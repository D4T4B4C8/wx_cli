ANTI-FORENSIC TECHNIQUES

Understanding methods used to conceal, alter, or destroy digital evidence and the forensic techniques used to detect and investigate them

DATA ENCRYPTION

THESE ARE TECHNIQUES ATTACKERS USE. ENCRYPTING DATA STORED ON DIGITAL DEVICES OR TRANSMITTED OVER NETWORKS TO PREVENT UNAUTHORIZED ACCESS AND ANALYSIS BY FORENSIC INVESTIGATORS.
TOOLS
apt install gnupg
— or —
gpg --symmetric f.txt
— or —
gpg --decrypt flag.gpg

DATA DELETION AND WIPING

PERMANENTLY ERASING OR OVERWRITING DATA ON STORAGE DEVICES TO MAKE IT UNRECOVERABLE.
TOOLS
shred -n 3 o.txt
— or —
dd if=/dev/urandom of=o.txt bs=1M count=5
OVERWRITES 3 TIMES WITH RANDOM DATA OVERWRITES 5 TIMES - 1M = SPEED 1 MBPS THE MORE YOU OVERWRITE A FILE WITH RANDOM DATA THE MORE SECURE THE DELETION BECOMES.

STEGANOGRAPHY

HIDING SENSITIVE DATA WITHIN SEEMINGLY INNOCUOUS FILES OR MEDIA TO EVADE DETECTION. STEGANOGRAPHY HAS MANY TECHNIQUES, ALREADY COVERED SEPARATELY IN MY WEB PAGE NOTES.

FILE AND METADATA MANIPULATION

ALTERING FILE TIMESTAMPS, METADATA, AND OTHER ATTRIBUTES TO MISLEAD INVESTIGATORS ABOUT THE ORIGIN OR TIMELINE OF DIGITAL EVIDENCE.
FILE AND METADATA MANIPULATION TOOLS
touch -a -m -t YYYYMMDDHHMM.SS 0.jpg
— or —
chmod 644 0.jpg
example: 202205061123.30 THIS CMD CHANGE THE "MODIFICATION DATE/TIME" OF A FILE THIS CMD CHANGE THE "ACCESS DATE/TIME" AND "INODE CHANGE DATE/TIME" TO CURRENT TIME

FILE FRAGMENTATION AND DISPERSAL

split my.jpg out --bytes=10m
— or —
cat 1.jpg 2.jpg 3.jpg > new.jpg
FRAGMENTING FILES INTO SMALLER PIECES AND DISPERSING THEM ACROSS MULTIPLE LOCATIONS TO MAKE RECONSTRUCTION AND ANALYSIS MORE DIFFICULT. SPLITS INTO 10MB CHUNKS THIS CMD MERGES ALL SPLIT FILES BACK TO THE ORIGINAL FILE
