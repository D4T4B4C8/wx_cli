PASSWORD CRACKING

Exploring Common Password Attacks

BRUTE FORCE ATTACK

BRUTE FORCE ATTACK INVOLVES SYSTEMATICALLY TRYING ALL POSSIBLE COMBINATIONS OF CHARACTERS UNTIL THE CORRECT PASSWORD IS FOUND. THIS METHOD GUARANTEES SUCCESS BUT CAN BE TIME CONSUMING, ESPECIALLY FOR COMPLEX PASSWORDS.
TOOLS
zip2john my.zip > hash.txt
— or —
john hash.txt
— or —
fcrackzip -b -c a -l 1-6 my.zip
— or —
hashcat -a3 -m0 hash.txt ?a?a?a?a?a?a
RUN HASHCAT ON RDP - MD5 MASK EXAMPLE ABOVE

DICTIONARY ATTACK

DICTIONARY ATTACKS USE A PREDEFINED LIST OF POSSIBLE PASSWORDS AND TEST EACH ONE. THIS METHOD IS FASTER THAN BRUTE FORCE BUT ONLY WORKS IF THE PASSWORD IS IN THE DICTIONARY.
TOOLS
john --wordlist=pass hash.txt
— or —
hydra -l username -p pass.dst ip -t4 ssh
— or —
hashcat -a0 -m0 hash.txt pass.txt
— or —
fcrackzip -D -p word.txt my.zip
— or —
pdfcrack -f my.pdf

RAINBOW TABLES

RAINBOW TABLES ARE PRECOMPUTED TABLES OF HASH VALUES FOR ALL POSSIBLE PASSWORD COMBINATIONS. THEY SIGNIFICANTLY SPEED UP THE PROCESS OF REVERSING CRYPTOGRAPHIC HASH FUNCTIONS.

HYBRID ATTACK

HYBRID ATTACKS COMBINE DICTIONARY AND BRUTE FORCE ATTACKS. THEY START WITH A DICTIONARY ATTACK AND THEN APPEND OR PREPEND ADDITIONAL CHARACTERS TO EACH WORD IN THE DICTIONARY.
TOOLS
hashcat -a6 -m0 hash.txt wordlist.txt ?d?d
