LINUX NETWORK FORENSICS

IF YOU HAVE DISCOVERED A LINUX LAPTOP AT A CRIME LOCATION AND NEED TO PERFORM NETWORK FORENSICS, YOUR MAIN FOCUS WILL LIKELY BE TO ANALYZE EVIDENCE OF NETWORK ACTIVITY, INCLUDING CONNECTIONS MADE BY THE DEVICE, ANY NETWORK CONFIGURATION, AND LOGS OF PREVIOUS SESSIONS.

IDENTIFY AND CAPTURE NETWORK CONFIGURATION

TO UNDERSTAND THE LAPTOP'S NETWORK BEHAVIOR, FIRST CAPTURE INFORMATION ABOUT NETWORK CONFIGURATIONS AND RECENT ACTIVITY.
CHECK ACTIVE NETWORK INTERFACE
ip addr show
LIST SAVED NETWORK CONFIGURATIONS
cat /etc/NetworkManager/system-connections/*
VIEW RECENT ARP TABLE ENTRIES
arp -a
VIEW ROUTING TABLE
ip route show
THE ROUTING TABLE CAN PROVIDE INFORMATION ON THE NETWORK STRUCTURE AND GATEWAYS PREVIOUSLY USED.

EXAMINE LOGS FOR NETWORK ACTIVITY

SYSTEM LOGS
cd /var/log
— or —
grep -r "network"
APPLICATION LOGS
sqlite3 ~/.mozilla/firefox/*.default-release/places.sqlite "SELECT url FROM moz_places;"
LOOKS FOR BROWSING HISTORY FILES, WHICH CAN PROVIDE INSIGHT INTO VISITED WEBSITES.
VPN/PROXY LOGS
IF THE LAPTOP WAS CONNECTED TO A VPN OR USED A PROXY, LOOK FOR CONFIGURATION FILES AND LOGS IN /etc OR ~/.config

CHECK RECENT CONNECTIONS

NETWORK SERVICES
ss -tuln
LIST OPEN PORTS AND ACTIVE NETWORK SERVICES.
CHECK RECENT SSH OR REMOTE ACCESS CONNECTIONS
cat ~/.bash_history | grep ssh
— or —
cat ~/.zsh_history | grep ssh
INSPECT LAST ACCESSED IP
netstat -anp | grep 'ESTABLISHED'

ANALYZE TRAFFIC DUMPS

IF YOU FIND ANY .PCAP FILES OR SIMILAR ON THE LAPTOP, THEY MAY CONTAIN RECORDED NETWORK TRAFFIC.
SEARCH FOR .PCAP FILES
find / -name "*.pcap"
ANALYZE PCAP FILE WITH TSHARK
tshark -r a.pcap
— or —
tshark -r a.pcap -Y "http.request or dns"
LOOK FOR SUSPICIOUS TRAFFIC. USE FILTERS FOR SPECIFIC TRAFFIC PATTERNS, SUCH AS DNS REQUESTS, HTTP TRAFFIC, OR SUSPICIOUS IPS.
AFTER RUN THIS CMD I FOUND "LOGIN.PHP"
GAIN MORE INFO ABOUT LOGIN.PHP
tshark -r a.pcap -Y "http.request and http contains \"login.php\"" -T fields -e http.request.method -e http.host -e http.request.uri
— or —
tshark -r a.pcap -Y "http.response and http contains \"login.php\"" -T fields -e http.response.code -e http.file_data
— or —
tshark -r a.pcap -Y "http.request.method == \"POST\"" -T fields -e http.file_data
— or —
tshark -r a.pcap -Y "http.referer and http contains \"login.php\"" -T fields -e http.referer
— or —
tshark -r a.pcap -Y "http contains \"login.php\"" -T fields -e ip.src -e ip.dst
— or —
whois [ip]
— or —
tshark -r a.pcap --export-objects "http,/home/whitex"
— or —
tshark -r a.pcap -Y "http.request and http contains \"user.php\"" -T fields -e http.request.full_uri | sort | uniq

EXAMINE DNS CACHE FOR RECENTLY RESOLVED HOSTS

sudo cat /etc/resolv.conf
— or —
whois [ip]
IT PROVIDES VALUABLE INFORMATION ABOUT RECENTLY RESOLVED DOMAIN NAMES. IT IS HELPFUL FOR TRACKING THE WEBSITE, SERVERS OR SERVICES A DEVICE HAS RECENTLY INTERACTED WITH.

USER AND COMMAND HISTORY

cat ~/.bash_history | grep -E 'wget|curl|ssh|ftp'
— or —
cat ~/.zsh_history | grep -E 'wget|curl|ssh|ftp'
— or —
ls ~/.ssh/
LOOK IN .bash_history, .zsh_history OR SIMILAR FILES IN THE USER'S HOME DIRECTORY TO SEE IF ANY COMMANDS RELATED TO NETWORKING. CHECK FOR SSH KEYS. IF THE USER CONNECTED TO OTHER SYSTEMS, THERE MAY BE SSH KEYS.

EXTRACT AND ANALYZE BROWSER ARTIFACTS

sqlite3 ~/.mozilla/firefox/*.default-release/cookies.sqlite "SELECT host, name, value FROM moz_cookies;"
— or —
sqlite3 ~/.mozilla/firefox/*.default-release/places.sqlite "SELECT url, datetime(last_visit_date/1000000, 'unixepoch') FROM moz_places WHERE url LIKE '%download%';"
IF THE USER ACCESSED REMOTE RESOURCES VIA A WEB BROWSER, BROWSER ARTIFACTS MAY REVEAL LOGIN CREDENTIALS, BROWSING HISTORY AND SESSION COOKIES. BROWSER COOKIES AND CACHE MAY SHOW DETAILS OF VISITED SITES AND SAVED CREDENTIALS. LOOK IN THE BROWSER DOWNLOAD HISTORY FOR EVIDENCE OF FILES DOWNLOADED DURING SUSPICIOUS ACTIVITY.

LIVE NETWORK CAPTURE

tcpdump -i wlan0 -w a.pcap
— or —
tshark -i wlan0 -w a.pcap
— or —
ngrep -d wlan0
— or —
tcpdump -r a.pcap
— or —
tshark -r a.pcap
— or —
zeek -r a.pcap
IF THE DEVICE IS ACTIVE AND CONNECTED TO A NETWORK, YOU COULD PERFORM A LIVE CAPTURE TO MONITOR ONGOING ACTIVITY. LOOK FOR UNUSUAL TRAFFIC PATTERNS SUCH AS HIGH FREQUENCY DNS QUERIES, CONNECTIONS TO SUSPICIOUS IP ADDRESSES, OR FILE TRANSFERS.
