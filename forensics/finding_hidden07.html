FIRST INSTALL REGISTRY EXPLORER HOW TO FIND HIVES FILE hives = SAM, SECURITY, SOFTWARE, SYSTEM
2) REGLOOKUP
reglookup -h -t key -p "/sam/domains" sam
THIS SHOWS HEADERS LIKE: PATH, TYPE, VALUES, MTIME]
-p "/sam/domains" IS USED TO GO INSIDE THE HIVE FILE TO A SPECIFIC LOCATION
-t KEY IS USED TO SHOW RESULTS ONLY FOR A SPECIFIC DATA TYPE
-t DATA TYPE OPTIONS]: NONE, SZ, EXPAND_SZ, BINARY, DWORD, DWORD_BE, LINK, MULTI-SZ, KEY, RSRC_LIST, RSRC_DESC, QWORD

— or —
reglookup -h -s -t key -p "/sam/domains" sam

NETWORK TRAFFIC ANALYSIS

MONITORING AND ANALYZING NETWORK TRAFFIC FOR HIDDEN COMMUNICATION OR DATA EXFILTRATION.
TOOLS
1) WIRESHARK
wireshark -i wlan0
— or —
sudo wireshark data.pcap
OPEN TEST LOGIN PAGE IN YOUR BROWSER AND TYPE ANY USERNAME AND PASSWORD SAVE FILE AS DATA.PCAP
SEARCH] -> http.request.method == "post"
2) TSHARK
tshark -r data.pcap -Y "http.request.method == POST" -T fields -e ip.src -e ip.dst -e http.request.uri
— or —
tshark -r data.pcap -Y 'http.request.uri contains "userinfo.php"' -T fields -e tcp.stream
— or —
tshark -r data.pcap -Y 'tcp.stream eq 89' -w new.pcap
— or —
tshark -r new.pcap -Y "http.request.method == POST" -V
THIS CMD SHOWS POST REQUESTS THIS CMD SHOWS THE STREAM NUMBER OF USERINFO.PHP THIS CMD EXTRACTS THE USERINFO.PHP STREAM INTO NEW.PCAP

SLACK SPACE ANALYSIS

INVESTIGATING SLACK SPACE, THE UNUSED SPACE WITHIN A DISK CLUSTER, FOR HIDDEN DATA.
TOOLS
FOREMOST
sudo dd if=/dev/sdb of=data.img bs=4M
— or —
mmls data.img
— or —
fsstat -o 103216 data.img
— or —
fls -f fat32 -o 103216 -r data.img
— or —
istat -f fat32 -o 103216 data.img 256
— or —
blkls -f fat32 -o 103216 data.img > new.img
— or —
foremost -i new.img
CREATE SDB TO IMG USE FOR IDENTIFY PARTITIONS CHECK FILE SYSTEM TYPE - 103216 IS THE START NUM LIST ALL THE DATA INCLUDING DELETED FILES/DIRECTORY - FILE SYSTEM TYPE FAT32, START 103216 IT GIVES FULL INFO ABOUT A SPECIFIC FILE - 256 IS THE INODE NUMBER THIS CMD EXTRACTS SLACK SPACE IN DATA.IMG
