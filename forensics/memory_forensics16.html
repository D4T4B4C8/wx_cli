MEMORY FORENSICS INTRODUCTION TO VOLATILITY

Memory acquisition is the process of capturing the contents of a computer's RAM to analyze it later.

INTRODUCTION TO VOLATILITY

Volatility is an open-source memory forensics framework for incident response and malware analysis. It allows investigators to extract digital artifacts from volatile memory (RAM) dumps. Volatility supports memory dumps from a wide variety of operating systems, including Windows, Linux, Mac, and Android. There are two types of Volatility tools: 1) Volatility 2 -> Download using GitHub 2) Volatility 3 -> pacman -S volatility

WINDOWS MEMORY ACQUISITION - WINPMEM AND DUMPIT
