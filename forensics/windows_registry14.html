WINDOWS REGISTRY FORENSICS

The Windows registry is a hierarchical database that stores low-level settings for the OS and for applications.

HIVES

1) SYSTEM
Stores system configurations and services.
2) SOFTWARE
Stores installed software and configurations.
3) SECURITY
Stores security settings and policies.
4) SAM
Stores user account information.
5) NTUSER.DAT
Stores user-specific configuration for each user. All hives are stored in Windows/System32/config. Hives are stored in two separate locations:

HKEY_LOCAL_MACHINE (HKLM)

system wide settings are stored. Files: SAM, SYSTEM, SOFTWARE, SECURITY.
HKLM HIVE LOCATION EXAMPLE - SERVICES
SYSTEM/ControlSet001/Services/ This location shows a list of all installed services and drivers. REGLOOKUP SYSTEM - IF YOU DON'T KNOW THE PATH
TOOLS

INVESTIGATING WINDOWS LOGS

I already covered how to install evtx tools and convert Windows logs (.evtx) to .xml, along with all Windows log locations. Here are alternative methods for reading logs.
METHOD 1: EVTX_DUMP.PY
.local/bin/evtx_dump.py log.evtx
Useful when you don't want to convert the evtx file to xml.
METHOD 2: XMLLINT
pacman -S libxml2
— or —
xmllint --format log.xml
METHOD 3: XMLSTARLET
pacman -S xmlstarlet
— or —
xmlstarlet fo log.xml
Both xmllint and xmlstarlet are used to pretty-print and open XML files.
METHOD 4: CONVERT XML TO JSON
pip install yq
— or —
xq . log.xml > log.json
— or —
jq . log.json
