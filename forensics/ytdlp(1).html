YT-DLP Youtube-DL

Media Extraction Protocol — Command Reference

YT-DLP

Install
sudo pacman -S yt-dlp
— or —
pip install 'yt-dlp>=2022.1.21'
Show video quality list
yt-dlp -F link
Download
yt-dlp -f 102 link
102 = quality number from the list above

Youtube-DL

Show video quality list
youtube-dl -F link
Download
youtube-dl -f best link
best = used for best available quality
Link Status: Encrypted Protocol: Stable
