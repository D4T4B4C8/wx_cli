LINUX FORENSICS

Understanding Linux forensic investigation techniques for analyzing system activity, files, logs, user behavior, and digital evidence

VOLATILE DATA

Volatile data is information that resides in RAM and is lost when the system is powered down or restarted.
1.1) RUNNING PROCESSES
RUNNING PROCESSES - WINDOWS
Get-Process | Format-Table -AutoSize
RUNNING PROCESSES - LINUX
ps aux > out.txt
1.2) LIST NETWORK CONNECTIONS
LIST NETWORK CONNECTIONS - WINDOWS
Get-NetTCPConnection | Format-Table -AutoSize
LIST NETWORK CONNECTIONS - LINUX
netstat -tuln > out.txt
— or —
ss -tuln
1.3) LIST LOADED DRIVERS / KERNEL MODULES
LIST LOADED DRIVERS / KERNEL MODULES - WINDOWS
Get-WmiObject Win32_SystemDriver | Format-Table -AutoSize
LIST LOADED DRIVERS / KERNEL MODULES - LINUX
lsmod > out.txt
1.4) SAVE OPEN FILES - LINUX
lsof > out.txt
1.5) SAVE SYSTEM LOGS - LINUX
journalctl > out.txt

NON-VOLATILE DATA

Non-volatile data is information that is stored on disk and persists across reboots.
2.1) Configuration files:
cp -R /etc etc_backup
2.2) User data:
tar -cvzf home_bkup.tar.gz /home/wx
2.3) System logs:
cp -R /var/log log_bkup

LINUX FILE SYSTEM AND ANALYSIS

The Linux file system is hierarchical, with the root directory ('/') at the top and various subdirectories. 3.1. / - Root directory, the starting point of the file system. 3.2. /bin - Essential user command binaries (executables). 3.3. /sbin - Essential system binaries. 3.4. /etc - Configuration files. 3.5. /home - User home directories. 3.6. /lib - Essential shared libraries and kernel modules. 3.7. /usr - Secondary hierarchy for user utilities and applications. 3.8. /var - Variable files, like logs and databases. 3.9. /tmp - Temporary files.

COMMON FILE SYSTEMS IN LINUX

4.1) EXT4 - Fourth extended file system, widely used. 4.2) XFS - High performance journaling file system. 4.3) BTRFS - B-Tree file system, with advanced features like snapshots. 4.4) REISER-FS - A journaling file system known for efficient small file handling.

Create a disk image. Mount the disk image. Identify partitions. Check file system type. 239616 is the partition start sector number. List all files in the partition, including deleted files. ntfs=file system type Extract a file into your system. 261 is the file inode/entry number.
