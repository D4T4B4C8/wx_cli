BOOTING PROCESS

Understanding the step-by-step process that takes a computer from power-on to a fully loaded operating system

LINUX BOOT PROCESS

BIOS/UEFI INITIALIZATION
WHEN THE COMPUTER IS TURNED ON THE BIOS (BASIC INPUT/OUTPUT SYSTEM) OR UEFI (UNIFIED EXTENSIBLE FIRMWARE INTERFACE) INITIALIZES THE HARDWARE. EXAMPLE: THE BIOS PERFORMS POST (POWER ON SELF TEST) TO CHECK THE HARDWARE COMPONENTS.
BOOTLOADER STAGE
THE BIOS/UEFI LOOKS FOR A BOOTLOADER ON THE STORAGE DEVICE (LIKE GRUB - GRAND UNIFIED BOOTLOADER). EXAMPLE: GRUB IS LOADED FROM THE MASTER BOOT RECORD (MBR).
KERNEL LOADING
THE BOOTLOADER LOADS THE LINUX KERNEL INTO MEMORY. EXAMPLE: GRUB LOADS THE KERNEL FILE (EG "/boot/vmlinuz-linux").
INIT SYSTEM
THE KERNEL STARTS THE INITIAL PROCESS ("INIT" OR "SYSTEMD") WHICH MANAGES SYSTEM INITIALIZATION. EXAMPLE: SYSTEMD STARTS AND MANAGES THE SYSTEM SERVICES.
TARGETS
THE SYSTEM ENTERS A SPECIFIC TARGET WHICH DEFINES THE STATE OF THE MACHINE. EXAMPLE: THE SYSTEM ENTERS GRAPHICAL MODE FOR THE USER LOGIN SCREEN.

WINDOWS BOOT PROCESS (BIOS/UEFI INITIALIZATION)

THE COMPUTER'S BIOS OR UEFI INITIALIZES THE HARDWARE AND PERFORMS A POST. EXAMPLE: THE BIOS CHECKS THE RAM AND OTHER COMPONENTS.
BOOT MANAGER
THE BIOS/UEFI LOADS THE WINDOWS BOOT MANAGER (BOOTMGR.EXE). EXAMPLE: BOOT MANAGER IS FOUND ON THE ACTIVE PARTITION.
BOOT LOADER
BOOT MANAGER LOADS THE WINDOWS OS LOADER (WINLOAD.EXE). EXAMPLE: WINLOAD.EXE LOADS ESSENTIAL DRIVERS AND THE KERNEL (NTOSKRNL.EXE).
KERNEL INITIALIZATION
THE KERNEL INITIALIZES THE HAL (HARDWARE ABSTRACTION LAYER) AND CORE SYSTEM PROCESSES. EXAMPLE: NTOSKRNL.EXE STARTS ESSENTIAL SERVICES AND DRIVERS.
SESSION MANAGER
THE SESSION MANAGER SUBSYSTEM (SMSS.EXE) INITIALIZES USER SESSIONS. EXAMPLE: SMSS.EXE SETS UP THE SYSTEM ENVIRONMENT AND LOADS THE WINLOGON PROCESS.
WINLOGON AND EXPLORER
THE WINLOGON PROCESS (WINLOGON.EXE) HANDLES USER LOGIN. EXAMPLE: AFTER LOGIN "EXPLORER.EXE" IS STARTED, LAUNCHING THE WINDOWS DESKTOP ENVIRONMENT.

MAC OS BOOT PROCESS - EFI INITIALIZATION

THE MAC EFI (EXTENSIBLE FIRMWARE INTERFACE) INITIALIZES THE HARDWARE. EXAMPLE: EFI PERFORMS A HARDWARE CHECK SIMILAR TO POST.
BOOT.EFI
EFI LOADS THE "BOOT.EFI" FILE, WHICH IS THE MAC BOOT LOADER. EXAMPLE: BOOT.EFI IS LOCATED IN THE EFI SYSTEM PARTITION.
KERNEL LOADING
BOOT.EFI LOADS THE MACOS KERNEL (MACH-KERNEL). EXAMPLE: MACH-KERNEL IS LOADED INTO MEMORY.
LAUNCHD
THE KERNEL STARTS THE LAUNCHD PROCESS WHICH MANAGES SYSTEM INITIALIZATION AND SERVICES. EXAMPLE: LAUNCHD REPLACES THE OLDER "INIT" PROCESS.
SYSTEM INITIALIZATION
"LAUNCHD" INITIALIZES SYSTEM SERVICES AND STARTS THE LOGIN WINDOW. EXAMPLE: "LAUNCHD" STARTS SERVICES LIKE THE WINDOW SERVER AND USER ENVIRONMENT.

BOOTING PROCESS - EXAMPLE SCENARIO SUMMARY

IMAGINE YOU PRESS THE POWER BUTTON ON THREE DIFFERENT COMPUTERS: ONE RUNNING LINUX, ONE WINDOWS, AND ONE MAC OS.
LINUX
THE BIOS INITIALIZES HARDWARE, GRUB LOADS, THE LINUX KERNEL STARTS, "SYSTEMD" INITIALIZES, AND YOU SEE THE LOGIN SCREEN.
WINDOWS
THE BIOS INITIALIZES HARDWARE, THE WINDOWS BOOT MANAGER LOADS, "WINLOAD.EXE" STARTS THE KERNEL, SMSS.EXE SETS UP THE SYSTEM, AND YOU SEE THE WINDOWS LOGIN SCREEN.
MAC
THE EFI INITIALIZES HARDWARE, BOOT.EFI LOADS, THE MAC KERNEL STARTS, "LAUNCHD" INITIALIZES, AND YOU SEE THE MAC LOGIN SCREEN.
