DARK WEB FORENSICS

Investigating hidden online environments to identify digital evidence, trace activities, and support secure and lawful forensic investigations

UNDERSTANDING DARK WEB

1.1) STRUCTURE AND ACCESSIBILITY
DARK WEB IS A SMALL PART OF THE DEEP WEB, WHICH INCLUDES ALL ONLINE CONTENT NOT INDEXED BY TRADITIONAL SEARCH ENGINES. THE DARK WEB REQUIRES SPECIFIC SOFTWARE LIKE TOR (THE ONION ROUTER) TO ACCESS.
1.2) COMMON USES
IT IS KNOWN FOR ILLEGAL ACTIVITIES SUCH AS DRUG TRAFFICKING, ILLEGAL ARMS SALES AND HUMAN TRAFFICKING. IT IS ALSO USED BY INDIVIDUALS SEEKING PRIVACY AND FREEDOM FROM CENSORSHIP, INCLUDING JOURNALISTS AND ACTIVISTS.
1.3) FORENSIC CHALLENGES
ANONYMITY AND ENCRYPTION
TRACKING INDIVIDUALS OR ACTIVITIES IS CHALLENGING DUE TO THE USE OF ENCRYPTION AND ANONYMITY TOOLS.

IDENTIFY TRACES OF TOR BROWSER IN LINUX

CHECK FOR TOR BROWSER DIRECTORY
ls ~/tor-browser_en-US
LIST CONTENTS OF THE TOR DATA DIRECTORY
ls ~/tor-browser_en-US/Browser/TorBrowser/Data
CHECK FOR RUNNING TOR PROCESSES
ps aux | grep tor
CHECK FOR ACTIVE NETWORK CONNECTIONS ON TYPICAL TOR PORTS
netstat -tulwn | grep 9050
SEARCH FOR TOR-RELATED LOGS IN SYSTEM LOGS
journalctl | grep tor
— or —
dmesg | grep tor

IDENTIFY TRACES OF TOR BROWSER IN WINDOWS

MOUNT WIN.DD
SEARCH FOR TOR BROWSER DIRECTORIES
find /mnt/win.dd -type d -iname "*tor*"
CHECK COMMON USER PROFILE DIRECTORIES
ls /mnt/win.dd/Users//AppData/Local
— or —
ls /mnt/win.dd/Users//AppData/Roaming
CHECK WINDOWS PREFETCH FILES
ls /mnt/windd/Windows/Prefetch | grep -i tor

PERFORMING TOR BROWSER FORENSICS

MOUNT WIN.DD
4.1) IDENTIFY INSTALLATION DIRECTORIES
ls /mnt/win.dd/Program Files
— or —
ls /mnt/win.dd/Program Files (x86)
— or —
ls /mnt/win.dd/Users//AppData/Local
— or —
ls /mnt/win.dd/Users//AppData/Roaming
— or —
ls /mnt/win.dd/Users//Downloads
TOR BROWSER CAN BE INSTALLED IN VARIOUS LOCATIONS. COMMON DIRECTORIES INCLUDE:
4.2) SEARCH FOR TOR BROWSER FILES AND DIRECTORIES
find /mnt/win.dd -type d -iname "*tor*"
— or —
find /mnt/win.dd -type f -iname "*tor*"
USE THE FIND COMMAND TO SEARCH FOR TOR-RELATED FILES AND DIRECTORIES.
4.3) ANALYZE BROWSER ARTIFACTS
ls /mnt/win.dd/Users//AppData/Local/Tor Browser
— or —
ls /mnt/win.dd/Users//AppData/Roaming/Tor Browser
CHECK FOR BROWSER ARTIFACTS SUCH AS HISTORY, CACHE, AND CONFIGURATION FILES.
4.4) INSPECT WINDOWS PREFETCH FILES
ls /mnt/win.dd/Windows/Prefetch | grep -i tor
WINDOWS PREFETCH FILES CAN INDICATE IF AND WHEN TOR BROWSER WAS EXECUTED.
4.5) EXAMINE WINDOWS EVENT LOGS
ls /mnt/win.dd/Windows/System32/winevt/Logs
LOOK AT THE WINDOWS EVENT LOGS FOR ANY ENTRIES RELATED TO TOR.
