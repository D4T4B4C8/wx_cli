DATA ACQUISITION

DATA ACQUISITION IS MAINTAINING THE INTEGRITY AND CHAIN OF CUSTODY OF DIGITAL EVIDENCE.
VARIOUS FORMATS ARE USED TO ENSURE THAT DATA IS PRESERVED ACCURATELY AND CAN BE ANALYZED EFFECTIVELY.

EO1 (ENCASE IMAGE FILE)

WIDELY USED IN FORENSIC INVESTIGATIONS FOR CAPTURING AND STORING COMPLETE DISK IMAGES.
ADVANTAGES
SUPPORTS COMPRESSION, ENCRYPTION, AND PRESERVES METADATA.
DISADVANTAGES
PROPRIETARY FORMAT, REQUIRES COMPATIBLE SOFTWARE FOR ANALYSIS.
TOOLS
sudo ewfacquire -t test /dev/sdb
— or —
sudo ftkimager --e01 --case-number 01 --evidence-number 01 --description xyz --examiner faizan --notes criminal /dev/sdb output

AFF (ADVANCE FORENSIC FORMAT)

COMMONLY USED FOR STORING AND SHARING FORENSIC IMAGES.
ADVANTAGES
SUPPORTS COMPRESSION AND ENCRYPTION
DISADVANTAGES
LESS WIDELY ADOPTED
TOOLS
affconvert input.raw output.aff
— or —
affcat out.aff
— or —
affuse out.aff /mnt/aff
— or —
affinfo out.aff
CONVERT RAW TO AFF DISPLAY THE CONTENTS OF AN AFF FILE MOUNTS AN AFF FILE DISPLAY METADATA ABOUT FILE

DD (RAW DISK IMAGE)

BASIC FORENSIC IMAGING FOR DISK CLONING AND ANALYSIS.
ADVANTAGES
SIMPLE, WIDELY SUPPORTED.
DISADVANTAGES
NO BUILT-IN SUPPORT FOR COMPRESSION, ENCRYPTION.
TOOLS
dd if=/dev/sda of=out.dd
— or —
dc3dd if=/dev/sda of=out.dd

SMART (SELF-MONITORING ANALYSIS AND REPORTING TECHNOLOGY)

USED FOR CREATING AND ANALYZING FORENSIC DISK IMAGES.
ADVANTAGES
OPEN FORMAT, SUPPORTS COMPRESSION AND ENCRYPTION.
DISADVANTAGES
LESS WIDELY ADOPTED, REQUIRES SPECIFIC TOOLS FOR FULL FUNCTIONALITY.
TOOLS
sudo pacman -S smartmontools
— or —
sudo smartctl -i /dev/sda1
— or —
sudo smartctl -s on /dev/sda
— or —
sudo smartctl -a /dev/sda1
— or —
sudo smartctl -t short /dev/sda
— or —
sudo smartctl -l selftest /dev/sda
