Case File // 002

EXPLORING EVIDENCE

USING E01 AFF DD

E01

MOUNT
sudo apt install ewf-tools
— or —
ewfmount evidence.e01 /mnt/ewf
WITHOUT MOUNT
mmls evidence.e01
— or —
fsstat -o 1032167 evidence.e01
— or —
fls -f ext4 -o 1032167 evidence.e01
— or —
fls -f ext4 -o 1032167 -r evidence.e01
— or —
fls -f ext4 -o 1032167 -r -p / evid.e01
— or —
icat -o 1032167 evid.e01 261 > a.jpg
IDENTIFY PARTITIONS CHECK FILE SYSTEM TYPE - 1032167 IS THE START NUMBER LIST FILE IN THE PARTITION - EXT4 IS THE FILE SYS TYPE LIST DIRECTORY FILES DISPLAY FULL PATH EXTRACT FILE - 261 IS THE FILE NUMBER

AFF

MOUNT
affuse evid.aff /mnt/aff
— or —
cd /mnt/aff ; ls
WITHOUT MOUNT
SAME AS E01

DD

MOUNT
sudo fdisk -l evid.dd
— or —
sudo parted evid.dd unit s print
— or —
mount -o loop,offset=1048576 evid.dd /mnt/dd
2048 * 512 = 1048576 PARTED -> START=2048, FDISK -> UNITS=512
WITHOUT MOUNT
SAME AS E01
