HOW TO HIDE ENCRYPTED TEXT IN JPEG



FIRST WE WILL ENCRYPT OUR TEXT TO AES-256-CBC



openssl enc -e -aes-256-cbc -iv SOF0 -K SOS -base64 <<< "lol man"

IN JPEG FILE



SOF0 = (START OF FRAME) KEY = 16 bit

SOS = (START OF SCAN) KEY = 32 bit IN AES-256

IF THE AES IS 192 THEN THE KEY IS 24 bit



IF THE AES IS 128 THEN THE KEY IS 16 bit



HOW TO FIND SOF0 AND 16 BIT KEY IN JPEG



hexedit --color a.jpeg

CTL + S



SEARCH FFC00011



SOF0 HEX CODE IS = FF C0 00 11

RESULT IS:

SKIP THIS: FF C0 00 11

08 01 46 00 DC 03 01 12 00 02 12 00 03 12 00 FF

COPY ALL 16 BIT CODE



SOF0 KEY = 0801 4600 DC03 0112 0002 1200 0312 00FF

NOW WE FIND SOS AND ITS 32 BIT KEY



SEARCH FFDA



SOS HEX CODE IS = FF DA

RESULT IS:

SKIP THIS: FF DA

00 0C 03 01 00 02 11 03 11 00 3F 00 C8 56 D9 60 BF ED A8 D0 62 1B EF AD 24 65 62 04 AA 89 BF 24

COPY ALL 32 BIT



SOS KEY = 000C 0301 0002 1103 1100 3F00 C856 D960 BFED A8D0 621B EFAD 2465 6204 AA89 BF24

NOW ITS TIME TO DECRYPT OUR MESSAGE



openssl enc -d -aes-256-cbc -iv 08014600DC030112000212000312 00FF -K 000C030112000211031100... -base64 >>> "ENC MESSAGE"

IF YOU WANT TO MORE SECURE YOUR ENC MESSAGE



cat > mess 

lol man

openssl enc -e -aes-256-cbc -iv SOF0 -K SOS -in mess > mess.enc

COPY THE ENC MESSAGE



echo "enc mess" | base64

NOW PASTE THIS ENC MESSAGE TO JPEG



IF YOU WANT TO DECRYPT THIS MORE SECURE ENC THEN REVERSE ALL THE STEPS



echo "enc mess" | base64 -d > mess.enc

openssl enc -d -aes-256-cbc -iv SOF0 -K SOS -in mess.enc
