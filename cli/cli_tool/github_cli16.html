HOW TO UPLOAD LARGE AMOUNT OF FILES AND FOLDER ON GITHUB USING CLI



FIRST OPEN



github -> settings -> developer option -> personal access token -> token (classic) -> create/regenerate token



WHEN YOU CREATE YOUR TOKEN TICK repo, workflow, write, delete, admin



> pacman -S github-cli

FOR LOGIN



> gh auth login

CHOOSE OPTION



> github.com



> https



> yes



> paste an authentication token



CREATING REPO



> gh repo create test --public

OR



> gh repo create test --private

LIST ALL REPO



> gh repo list

DELETE REPO



> gh repo delete username/repo-name

NOW WE START UPLOADING PROCESS



DELETE MAIN BRANCH USING CLI



> gh api -X DELETE /repos/w-h-i-t-e-x/wx_conf/git/refs/heads/main

> git init

> git config --global --add safe.directory /home/whitex

> git add .

IT ADD ALL FILES



> git status

> git remote add origin https://github.com/w-h-i-t-e-x/wx.git

IF YOU WANT TO ADD ANOTHER URL FIRST REMOVE OLD URL



> git remote remove origin

> git commit -m "any msg"

> git push origin master
