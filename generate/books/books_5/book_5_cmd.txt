$corrupted_boot35
* HOW TO RECOVER CORRUPTED BOOT PARTITION

-> sudo mount /dev/sdb2 /mnt
-> sudo mount /dev/sdb1 /mnt/boot
-> sudo mount --bind /dev /mnt/dev
-> sudo mount --bind /proc /mnt/proc
-> sudo mount --bind /sys /mnt/sys
-> sudo mount -t devpts devpts /mnt/dev/pts
-> sudo mount --bind /etc/resolv.conf /mnt/etc/resolv.conf
-> lsblk -f
-> mkfs.fat -F32 /dev/sdb1

-> sudo chroot /mnt
-> sudo mount -t efivarfs efivarfs /sys/firmware/efi/efivars
-> sudo pacman -S grub efibootmgr linux
-> sudo grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB --recheck
-> sudo mkinitcpio -P
-> sudo grub-mkconfig -o /boot/grub/grub.cfg

[NOW RESTART]

[IF ITS GIVE ERROR IN UUID AND OPEN EMERGENCY SHELL THEN ENTER PASSWD]

$smb39
* CREATE LOCAL SMB SHARING SETUP FOR WINDOWS AND ANDROID

-> sudo pacman -Sy smb samba
-> mkdir -p share
-> chmod -R 777 share
-> sudo chown -R $(whoami):$(whoami) share

[CREATE CONFIG FILE]
[INSIDE CONFIG FILE MENTION YOUR "SHARE" FOLDER NAME IS IMPORTANT]
-> sudo micro /etc/samba/smb.conf
   [SHARE]
   path = /home/whitex/share
   browseable = yes
   writable = yes
   read only = no
   guest ok = no
   valid users = whitex
   force user = whitex
   create mask = 0777
   directory mask = 0777

	[GLOBAL]
	kernel change notify = yes

[SAVE THE CONF FILE]

-> sudo smbpasswd -a whitex
-> sudo systemctl start smb
-> sudo systemctl enable smb
