[-loop 1 -t 5 -i 5.jpg]

2. Add a filter chain for it — copy the pattern, using [4:v] (since it's the 5th input, index 4) and label it [v4]:

[[4:v]scale=1280:720:force_original_aspect_ratio=decrease,pad=1280:720:(ow-iw)/2:(oh-ih)/2,setsar=1,fade=t=out:st=4:d=1[v4];]

3. Update the concat line — add [v4] and change n=4 to n=5:

[[v0][v1][v2][v3][v4]concat=n=5:v=1:a=0,format=yuv420p[v]]

4. Update the audio map — since audio is now the 6th input (index 5), change -map 4:a to -map 5:a.
