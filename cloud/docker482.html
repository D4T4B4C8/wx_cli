HOW TO RUN MANY OS IN ONE OS USING DOCKER



apt install podman

It is a subsitute of Docker



Now install distrobox



curl -s https://raw.githubusercontent.com/89luca89/distrobox/main/install | sudo sh

Now install kali linux



distrobox-create -n kali --image docker.io/kalilinux/kali-rolling:latest

see list of installed os



distrobox-list

open os



distrobox-enter kali

stop os



distrobox-stop kali

Remove os



distrobox-rm kali

for more info: Distrobox Github
